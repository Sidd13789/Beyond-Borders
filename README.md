# 🌍 Beyond Borders - Travel Website

Beyond Borders is a responsive travel website designed to help users discover beautiful destinations, explore travel packages, and book trips through an intuitive and modern interface. The project is built using HTML, CSS, and JavaScript with a focus on responsive design and user experience.

---

## ✨ Features

- 🏠 Attractive Landing Page
- 🎥 Background Video Hero Section
- 🔍 Destination Search UI
- 💰 Budget-based Price Slider
- 🌎 Popular Travel Destinations
- 📍 Detailed Location Information
- 🎒 Domestic & International Packages
- 📝 Online Booking Form
- 📞 Contact Page
- 👤 About Us Page
- 📱 Fully Responsive Design

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Boxicons
